# Fonturi pentru imaginile de previzualizare

Folosite doar la generarea imaginilor care apar când se trimite un link pe WhatsApp,
Facebook etc. (`src/lib/og.tsx`). Pe site, fonturile se încarcă prin `next/font`.

- Poppins (Light, SemiBold, Bold): SIL Open Font License 1.1, vezi `Poppins-OFL.txt`.
- Tinos (Regular, Bold), cu aceleași dimensiuni ca Times New Roman: SIL Open Font License 1.1,
  https://github.com/google/fonts/tree/main/ofl/tinos
